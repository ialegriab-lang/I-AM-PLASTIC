# Contenido estructurado

**De la información al documento digital.**

Repositorio didáctico para aprender a **investigar, seleccionar y jerarquizar contenido** antes de diseñar una página web.

El proyecto propone separar el proceso en etapas:

INFORMACIÓN → MARKDOWN → HTML SEMÁNTICO → CSS

## Archivos

- **`INFO.md`** · Guía conceptual sobre intención de comunicación, estructura y jerarquía. Se transformará en `index.html`.
- **`PROMPT.md`** · Instrucción base para trabajar con IA, organizar información en Markdown y convertirla posteriormente a HTML semántico.

## Objetivo

Construir documentos claros, consistentes y reutilizables. La IA ayuda a investigar y transformar la información; **la intención, la estructura y las decisiones del proyecto siguen siendo responsabilidad de quien diseña**.

## Uso

1. Define qué quieres comunicar.
2. Estructura y revisa el contenido en Markdown.
3. Transforma la versión aprobada a HTML.
4. Aplica el sistema visual con CSS.
